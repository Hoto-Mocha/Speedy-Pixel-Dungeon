# Speedy Pixel Dungeon

Speedy Pixel Dungeon은 [Shattered Pixel Dungeon](https://shatteredpixel.com/shatteredpd/)의 모드입니다.

# 바뀐 점

- 애니메이션 재생 속도가 5배 빠릅니다.
- 투사체 속도가 5배 빠릅니다.
- 마법 막대 투사체 속도가 5배 빠릅니다.
- 층 전환 간 컷신이 매우 짧습니다.

# 플레이 방법

PC로 플레이하는 경우 **desktop-[버전 이름].jar** 파일을 JRE로 직접 실행하여 플레이할 수 있습니다.

만약 Steam에서 Shattered Pixel Dungeon을 가지고 있다면 다음 방법을 통해 Steam에서 실행하여 플레이할 수 있습니다.

1. 먼저 [Releases 페이지](https://github.com/Hoto-Mocha/Speedy-Pixel-Dungeon/releases)에서 `desktop-[버전 이름].jar`파일을 다운로드합니다.

2. 라이브러리의 게임 타이틀을 우클릭하고 `속성...`을 클릭합니다.

3. **설치된 파일** 탭에서 `로컬 파일 탐색`을 클릭합니다.

4. `app`폴더를 엽니다.

5. `desktop-[버전 이름].jar`파일을 찾습니다.

6. 이 곳에서 다운로드받은 `desktop-[버전 이름].jar`파일의 이름을 해당 파일의 이름(`desktop-[버전 이름].jar`)과 동일하게 변경합니다. 원한다면 원본 게임의 파일을 백업해 둘 수 있습니다.

7. Shattered Pixel Dungeon의 **.jar** 파일을 방금 이름을 변경한 파일로 덮어씌웁니다.

8. **Shattered Pixel Dungeon**을 Steam에서 실행합니다.

9. 만약 게임을 원래대로 되돌리고 싶다면, Steam에서 `무결성 검사`를 실행하거나, 덮어씌운 파일을 백업해 두었던 원본 게임 파일로 다시 덮어씌웁니다.
